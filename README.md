# MockMentor – Your AI Powered Mock Interview Partner🎙️💼

A modern and intuitive solution designed to help you practice and improve interview skills through realistic AI conversations, with smart feedback to help you grow with every session.






## 🧠 How It Works

1. User **initiates a connection** with the AI assistant (built with Vapi).
2. The assistant **asks a series of predefined interview questions** and records user responses.
3. After the session, responses are **sent to a  API**.
4. The API **passes data to Gemini**, which analyzes it and generates smart feedback.
5. The final feedback and session data are **stored in Firebase** for future access.
